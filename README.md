# TOPSTER

앨범 커버로 나만의 취향 콜라주를 만드는 도구.

## 기능
- Last.fm API로 앨범 커버 검색
- 검색결과 클릭 또는 드래그앤드롭으로 그리드에 삽입
- 그리드 셀 클릭으로 삭제
- 그리드 사이즈 가변 조절 (최대 8×8)
- 컬러 슬라이더로 그리드 테두리/간격 색상 변경
- PNG 저장

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포

Vercel에 레포 연결 시 자동 배포됨. build command: `npm run build`, output directory: `dist`.
